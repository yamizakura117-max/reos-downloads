# REOS ダウンロード

Windows 10 / 11用のゲーム配布ページです。**GitHubアカウント・ログイン・Unityのインストールは不要です。**

## 初めて遊ぶ人へ（おすすめ）

[自動更新ランチャーをダウンロード](https://github.com/yamizakura117-max/reos-downloads/releases/download/launcher-v1.1.0/REOSLauncher-Windows-v1.1.zip)

1. ZIPを右クリックして「すべて展開」。
2. 展開したフォルダ内の `REOSLauncher.exe` を起動。
3. 初回のゲーム取得・更新が終わったら「プレイ」。

次回以降も同じランチャーから起動すると、新しいゲームを確認して更新します。友達にはこのページかランチャーのリンクを送ってください。

## ゲーム一式を直接受け取る

[REOS 2026.11.25.83 ゲーム一式](https://github.com/yamizakura117-max/reos-downloads/releases/download/game-2026.11.25.83/REOS-Windows-20261125-83.zip)

ZIPをすべて展開し、`REOS/Reos.exe` を起動してください。`Reos_Data` やDLLも必要なので、EXEだけを抜き出さないでください。直接起動の場合は自動更新されません。

## 友達と遊ぶ

1. 全員がランチャーで更新して「マルチプレイ」を開きます。
2. 一人が「パーティーを作る」を選び、招待コードをコピーして友達に共有します。友達はコードを入力して「パーティーに参加」を押します。
3. 一緒に練習する場合は、リーダーが「練習」を選びます。友達同士で対戦する場合は「通常」か「クイック」を選び、相手側に入る人が「対戦チームを変更」を押します。
4. 各自がキャラと覚醒を選んで準備を確定します。全員に「READY」が出たらリーダーが「試合開始」を押せます。

別パーティーとの自動マッチングとランクポイントの本番運用は準備中です。

## 更新と保存

- ランチャーの保存先は `%LOCALAPPDATA%\REOSLauncher`。
- 更新後は現在のゲーム1版だけを残します。「前の版に戻す」は必要なときに直前の版を再ダウンロードします。
- ゲームのセーブ・設定は更新で削除しません。
- ランチャーが更新するのはゲーム本体です。ランチャー自体の自己更新は未対応です。
- この公開リポジトリには配布ファイルと案内だけを置き、ゲームのソースコードは非公開にしています。
