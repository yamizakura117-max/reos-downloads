# REOS ダウンロード

[自動更新ランチャーをダウンロード](https://github.com/yamizakura117-max/reos-downloads/releases/download/launcher-v1.0.0/REOSLauncher-Windows-v1.zip)

1. ZIPを展開し、REOSLauncher.exeを起動。
2. 初回はゲームをダウンロード。完了したら「プレイ」。
3. 次回もランチャーから起動すると新しいゲームへ更新します。

Windows 10/11向け。GitHubアカウント不要。ゲームのソースコードは非公開です。
更新失敗時は保存済みの版を使用でき、直前の版へ戻す機能もあります。対戦相手とは同じ版を使用してください。
保存先は `%LOCALAPPDATA%\REOSLauncher`。ゲームのセーブデータは削除しません。
