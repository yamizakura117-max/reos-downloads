# REOS ダウンロード

Windows 10 / 11用のゲーム配布ページです。**GitHubアカウント・ログイン・Unityのインストールは不要です。**

## 初めて遊ぶ人へ（おすすめ）

[自動更新ランチャーをダウンロード](https://github.com/yamizakura117-max/reos-downloads/releases/download/launcher-v1.0.0/REOSLauncher-Windows-v1.zip)

1. ZIPを右クリックして「すべて展開」。
2. 展開したフォルダ内の `REOSLauncher.exe` を起動。
3. 初回のゲーム取得・更新が終わったら「プレイ」。

次回以降も同じランチャーから起動すると、新しいゲームを確認して更新します。友達にはこのページかランチャーのリンクを送ってください。

## ゲーム一式を直接受け取る

[REOS 2026.11.23.78 ゲーム一式](https://github.com/yamizakura117-max/reos-downloads/releases/download/game-2026.11.23.78/REOS-Windows-20261123-Roster78.zip)

ZIPをすべて展開し、`REOS/Reos.exe` を起動してください。`Reos_Data` やDLLも必要なので、EXEだけを抜き出さないでください。直接起動の場合は自動更新されません。

## 友達と対戦する

全員が同じゲームバージョンへ更新して「マルチプレイ」に進みます。ホストが部屋を作り、表示された部屋コードを参加者へ送ります。参加者はコードを入力して `JOIN ROOM`。キャラ・覚醒を選んで確定すると「READY」になります。全員がREADYになったら、ホストが「PLAY」で試合を開始してください。インターネット接続が必要です。

## 更新と保存

- ランチャーの保存先は `%LOCALAPPDATA%\REOSLauncher`。
- 更新後も前のゲーム版を保持し、「前の版に戻す」で切り替えられます。
- ゲームのセーブ・設定は更新で削除しません。
- ランチャーが更新するのはゲーム本体です。ランチャー自体の自己更新は未対応です。
- この公開リポジトリには配布ファイルと案内だけを置き、ゲームのソースコードは非公開にしています。
